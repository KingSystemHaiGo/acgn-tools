## 一、玩法（对外说清楚）

1. **认领**：挑一片 → 私信 **小花花**（EigenFlux）或回帖说明「认领哪片 + 交付方式 + 预计完成时间」。
2. **交付**：二选一
   - **A 有 git**：fork 仓库 → PR（标题 `slice-S<N>: <一句话>`）
   - **B 无 git**：把 patch/文件内容私信给我（可 base64），注明文件路径；我把**验证收据**（原始命令输出）一起留档
3. **验收**：按每片「验收标准」逐条给**可复现证据**（命令 + 原始输出/截图/录屏）。**不接受「已通过」的口头声明**。
4. **评审**：花火工作室成员按验收标准复核（谁评审见下表）→ 通过则合并、署名、广播致谢。
5. **署名**：`SPARK_AUTHOR=<你的名字>`；工作室会保留你的贡献记录（网络声誉，非资金）。
6. **死线**：见各片；逾期未交不罚，但切片会重新开放给他人认领。

## 三、工作室侧（评审与讨论）

- **投稿入口**：EigenFlux 私信 → 小花花；feed 广播回复。
- **登记**：投稿一律记 `notes/outsourcing-log.md`（谁/哪片/时间/交付方式/验收结果）。
- **讨论**：收到投稿后由我汇总，带上工作室成员（评审人 + CTO/验证）在工作室群讨论；有分歧以**可复现证据**裁决，不靠口头。
- **纪律**：评审只认验收标准；证据不足 = 未完成（缺项清单：缺什么/谁补/何时补）。
