## 0. 执行摘要

**结论：教育知识图谱 Agent 方向成立，且存在明确的差异化空位。** 现有方案分居两个象限互不重叠——通用知识图谱构建（GraphRAG/Graphiti 等）不懂教育语义；教育产品（Khanmigo/松鼠AI 等）有教育数据但图谱私有、不可验证。**"开放的、锚定课程标准的、可追溯的微知识点图谱 + 教育语义自动建图 agent"目前全球无一家产品同时具备。** 我们的 cn-primary-math-knowledge-graph（MIT 开源，95 学习目标 + 111 依赖边 + 19 课标锚点）已在这个空位先发。

**三个子问题初步结论**：
1. **边界**：自动构建 vs 人工确认——"候选自动生成、关系必须人审"是安全底线；证据链自动、结论人审
2. **教材兼容**：开放数据锚定课程标准（2022 版）而非任何教材版本，教材只作证据来源
3. **可验证性**：溯源 = evidence 链 + 一致性校验 = 冲突检测迁移，直接复用工作室验证底子

## 2. 竞品分析

### 2.1 通用知识图谱/PKM 工具（agent 化程度 0-5）

| 产品 | 定位 | agent化 | 图谱能力 | 教育适用性 | 借鉴点 |
|---|---|---|---|---|---|
| Roam Research | 块级双向链接笔记 | 1/5 | 双向链接范式，不可验证 | 无教育语义 | 依赖概念与知识依赖边同构 |
| Obsidian Graph View | 本地 Markdown 知识库 | 1.5/5 | 可视化成熟，无自主构建 | 教师可用，无锚点 | 本地优先+开放格式信任感 |
| Notion AI | 一体化工作区+AI | 2.5/5 | 关系库可建模，非自动 | 题库可以，无追踪 | 简单有效的产品形态 |
| Mem.ai | AI 优先个人记忆 | 2.5/5 | 嵌入检索非真图谱 | 低 | 证明自动组织体验好，但准确性差=图谱 grounding 的机会 |
| Rewind/Limitless | 屏幕/录音记忆 | 2/5 | 行为数据记忆图谱 | 低 | 多模态采集学习行为方向 |
| Khoj | 开源 AI 第二大脑 | 3/5 | 检索为主，无显式图谱 | 低 | 开源+本地部署安全性参照 |

**结论**：通用工具图谱可视化成熟，但**无一真正 agent 化**（自主读入、推理、更新图谱）。这是第一层空白。

|---|---|---|---|---|---|

| mem0 | 开源 AI 记忆层 | 3/5 | 实体/事实记忆自动提取 | 低 | 用户画像记忆+图谱结合 |

**结论**：通用建图技术成熟，但**不理解"课程标准/掌握度/依赖"语义**。教育语义自动建图是第三层空白。

### 2.4 小学教育知识图谱专门项目

**国内**：
- 国家中小学智慧教育平台（教育部）——按"学科→学段→单元→课时"组织内容，**无开放图谱**
- 《义务教育数学课程标准（2022 年版）》——"内容要求 183 条+学业要求"的官方来源，**是"可追溯"的唯一权威锚点**（本项目 19 个课标锚点的合法性基础）
- 北师大/华东师大知识图谱科研——论文多，**数据集基本不公开**【待核实】
- 松鼠AI/洋葱/作业帮——**全部黑盒**

**国际**：
- Khan Academy 技能树——API 可订阅但**不可导出为依赖图**【待核实】
- KT 公开数据集——作答-成绩数据，**非知识点依赖图谱**
- W3C 教育本体——学术社区存在，**无规模化落地**

**关键空白确认**：国内外没有公开、可验证、锚定官方课程标准、含微知识点依赖边的小学数学知识图谱数据集。**cn-primary-math-knowledge-graph 在该空白具备先发优势。**

## 3. 空白与机会点

### 3.1 空白定位（四象限）
- X 轴：通用知识图谱构建能力（GraphRAG/Graphiti 强）
- Y 轴：教育课标语义理解（教育产品强，但图不开放）
- **第一象限（教育+构建）几乎空白**——作业帮/松鼠AI 有教育数据无自动建图；GraphRAG 有建图技术不懂教育语义。**空心地带 = 第一象限。**

### 3.2 四个具体机会点
1. **课程知识图谱构建 Agent**：agent 自动读教科书/课标文本 → 输出带来源引用的微知识点与依赖边（LLM 抽取 + 规则校验 + 人工审阅闭环）
2. **可验证/可溯源作为护城河**：锚定 2022 课标 + 每条依赖可溯源 → 支撑"每步讲解可验证"，面向教师信任与家长审核——**黑盒商业产品无法抄袭的定位**
3. **教育语义掌握度 Agent**：在"依赖图+课标锚点"上做可解释诊断（"3 位数乘法错 → 根因 2 位数乘法未掌握"），对比松鼠AI 黑盒算法，**解释性即差异化**
4. **开源生态位**：中国无对标开放小学数学图谱，MIT 协议可建立标准影响力（教师可引用、开发者可集成）

### 3.3 风险提示
- 大模型数学能力强，"裸 LLM 辅导"可能稀释图谱价值——**必须以图作为 grounding 的强制件**而非装饰
- 商业化路径未验证——开源图谱难直接收费，可走"图谱+agent 服务"两段式
- 依赖边"soft"质量需社区长期维护——建议引入教材来源标注

## 4. 三个子问题分析（已登记工作室素材）

### 4.1 边界：自动构建 vs 人工确认
**原则：候选自动生成、关系必须人审；证据链自动、结论人审。**

- **可自动**：知识条目抽取（LLM）、候选依赖边生成、来源定位（课标条目/教材页码）、一致性初检
- **必须人审**：hard 依赖（认知必要关系）、跨版本映射确认、争议仲裁
- **机制**：review_queue（当前仓库已有 review_queue.json）——候选自动进队列，人工/专家审阅后提升为 reviewed
- **对标工作室验证底子**：这正对应 CD-4c 的"consume-gate"语义——自动生成的东西默认不可信，验证后才可消费

### 4.2 教材兼容：开放数据与教学体系的关系
**原则：锚定课程标准，不绑定任何教材版本；教材只作证据来源，不作唯一真相。**

- 锚点 = 《义务教育数学课程标准（2022 年版）》的能力要求（19 个 capability anchor 已建立）
- 同一概念可映射多个教材版本与学期（cross_edition_anchor_evidence.json 已有跨版本证据）
- 公开库不收录教材扫描页/OCR/习题全文/答案（PROVENANCE.md 已声明，规避版权风险）
- **对教育 agent 的含义**：图谱是"能力关系层"，教材是"内容供应层"，两层解耦后 agent 可服务于任何教材用户而不侵权

### 4.3 可验证性：溯源 + 一致性校验的教学形态
**原则：溯源 = evidence 链，一致性校验 = 冲突检测迁移。**

- **溯源（evidence 链）**：每个节点/边必须可追溯——来源（课标条目/教材活动/审核结论）+ 证据层级声明。教学场景形态 = 家长/教师可点击查看"这个知识点为什么这么排"
- **一致性校验（冲突检测）**：复用工作室 T002 冲突检测能力——新证据与既有图谱冲突时，进冲突检测流程（T001 规则已 APPROVED），仲裁后写入。教学形态 = 教材改版/课程标准更新时自动检测图谱漂移
- **版本历史**：依赖关系变更像代码一样可 diff、可回滚——教育场景 = 学习路径调整可解释
