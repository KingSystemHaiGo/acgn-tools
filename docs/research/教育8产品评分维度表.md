# 教育 8 产品 Agent 化评分维度表（RESEARCH-001 v0.2 补充）

> 用途：应 CatKing 对齐要求（2026-08-20）提供"评分项 + 权重"，用于与 CatKing 通用 28 产品矩阵对拍合并（CatKing 在 8/24 前将两版差异行标红合表）。
> 评分域：教育知识图谱 Agent 适配度（0~5 分，5 = 最契合"开放 + 锚定课标 + 可追溯微知识点图谱 + 教育语义自动建图"方向）。
> 配套：competitor_matrix.csv（原 28 产品 × 5 维）、CatKing-对齐记录.md（对齐结论）。

---

## 1. 评分维度与权重

| 维度 | 含义 | 权重 |
|---|---|---|
| 开放数据 | 图谱 / API 是否开放可获取（机器可读、可导出） | 30% |
| 课标锚定 | 是否锚定课标（中国 2022 义务教育课标为基准；非中国课标按映射折减） | 25% |
| 依赖边可追溯 | 知识点依赖边是否人审、可溯源、可验证（consume-gate 语义） | 20% |
| 教育语义正确 | 是否理解教育语义（区分知识点依赖边 vs 通用实体共现边） | 15% |
| agent 自构建 | 是否支持 / 已具备自动建图 agent 能力 | 10% |

综合分 = Σ(维度分 × 权重)，范围 0~5。

## 3. 与 CatKing 通用矩阵的合并约定（对齐结论落地）

- 通用建图基建（GraphRAG / Graphiti 等）行：CatKing 通用矩阵结论直接引用，本表不重复；其"通用建图层"评分与教育考试域评分分列，不混算。
- 八教育产品行：以上维度表与 CatKing 通用矩阵中同产品行对拍，差异行（开放数据 / 课标锚定维度）由 CatKing 在 8/24 前标红合表。
- 边界条件：依赖边人审 = consume-gate 语义、教材版本无关锚定课标 —— 已写入通用矩阵作为教育垂直边界条件（CatKing 确认）。
