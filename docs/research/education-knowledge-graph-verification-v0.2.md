## 逐项验证详情

### 1. IXL（美国 K12 自适应学习平台）

**验证动作（2026-08-18）**：
- `GET https://www.ixl.com/math/grade-3` → HTTP 200，页面含 29 处 "skill-plans"、123 处 "skills" 关键词
- `GET https://www.ixl.com/math/skill-plans` → HTTP 301（存在，跳转到可用页）

**结论**：IXL 的技能体系在网页层面**公开可浏览**（任何人都能看到技能列表与学习计划），但**不提供开放 API、结构化数据导出或下载**。原判断"知识点体系极细，私有"成立，补充精度：私有指"数据不可机器获取"，而非"内容完全不可见"。

**影响**：竞品矩阵中 IXL 的 agent化评分维持 2.5/5，"实时诊断报告"借鉴点成立。

### 2. 洋葱学园（国内微课平台）

**验证动作（2026-08-18）**：
- `GET https://www.yangcong345.com/` → HTTP 200，页面含 77 处 "AI"、1 处 "知识图谱"
- 具体上下文：`<div class="item-tag__text">知识图谱与AI思维链</div>`

**结论**：洋葱学园官网**明确宣传"知识图谱与AI思维链"**作为产品能力，但**无任何公开的知识图谱数据、API 或导出渠道**。原判断"图谱路径学习，私有"成立。

**影响**：竞品矩阵中洋葱学园维持 2/5，"微课+图谱结合"借鉴点成立，且进一步佐证"教育产品图谱全私有黑盒"的核心结论。

### 3. 北师大/华东师大知识图谱科研（数据集公开性）

**验证动作（2026-08-18）**：
- GitHub code/repo 检索（中文关键词"教育知识图谱 数据集"、"education knowledge graph BNU"、"knowledge graph education dataset chinese"）→ 无任何北师大/华东师大署名或国内高校的公开教育知识图谱数据集
- 中文检索结果被无关项目污染（funNLP 敏感词库、书籍列表等），侧面说明**该领域无知名开源数据集**；英文检索 BNU 相关结果为空

**结论**：原判断"论文多，数据集基本不公开"成立。公开渠道（GitHub）上**检索不到**北师大/华东师大的教育知识图谱数据集。

**影响**：强化"开放+锚定课标+可追溯微知识点图谱全球空白"的核心结论 —— 学术界的图谱数据同样封闭，开源先发位置更稀缺。

### 4. Khan Academy 技能树（API 可导出性）

**验证动作（2026-08-18）**：
- `GET https://www.khanacademy.org/api/v1/topics` → HTTP 400（反爬：`webpage handler can't process the URL`），官方 API 对无浏览器环境**不可直接访问**
- `GET https://developers.khanacademy.org/` → HTTP 200（开发者文档存在）
- GitHub 检索 `Khan/khan-exercises`（官方开源练习框架，1672 stars）→ 代码检索 "prerequisites" = **0 条结果**（练习文件为题目渲染模板，不含依赖边数据）
- GitHub 检索 `learningequality/ka-lite`（KA Lite，457 stars，KA 内容离线镜像）→ 存在，但定位是"离线内容服务"，非依赖图导出
- GitHub 检索社区工具：`jb-1980/khan-graphql`（5 stars，"Helper methods to get your data from Khan Academy"）→ **存在第三方非官方爬取先例**

**结论**：⚠️ 原判断需要**修正为部分成立**：
- "API 可订阅"：开发者文档存在（200），但实际 API 有反爬，官方不提供**稳定、受支持**的依赖图导出端点
- "不可导出为依赖图"：**部分成立** —— 官方通道无结构化依赖图导出；开源 khan-exercises 也不含 prerequisites；但社区存在非官方爬取先例（khan-graphql），技术上可行、工程上无保障

**影响**：竞品矩阵中 Khan Academy 技能树的定位从"完全不可导出"修正为"官方不可导出、社区可爬取"，不影响"Khan 系锚定美国 Common Core 非中国课标"的核心判断，反而强化差异化：连技术最开放的可汗学院都无官方结构化依赖图，我们的开放图谱先发优势成立。

### 5. 国家中小学智慧教育平台（开放图谱）

**验证动作（2026-08-18）**：
- `GET https://basic.smartedu.cn/` → HTTP 200，首页 HTML 无任何 `/api/` 痕迹
- `GET https://basic.smartedu.cn/tchMaterial`（教材资源页）→ HTTP 403（Forbidden，未开放抓取）

**结论**：原判断"按学科→学段→单元→课时组织内容，无开放图谱"成立。官方平台**无开放 API、无结构化图谱数据**。

**影响**：官方平台的内容组织方式（学科→学段→单元→课时）可作图谱结构参考，但数据不可获取，进一步确认"锚定课标 + 自建开放图谱"是唯一可行路径。

## 对核心结论的影响（汇总）

1. **5 处待核实全部闭环**：4 处原判断成立、1 处（Khan Academy）修正为"官方不可导出、社区可爬取"，**无一处推翻方向结论**。
2. **核心空白确认增强**：学术界（北师大/华东师大）与官方（教育部平台）数据均不公开，连技术开放度最高的 Khan Academy 也无官方依赖图导出 —— **"开放、可验证、锚定课标、含微知识点依赖边"的图谱全球空白这一结论，证据强度从"推断"升级为"多源实测确认"**。
3. **对数据包的影响**：竞品矩阵数据包（v0.2，28 产品 × 5 维）已按验证结果更新，IXL/洋葱学园/Khan/教育部平台 4 处标注 verified 证据，字节级验证收据见同目录 VERIFICATION_RECEIPT.json。
